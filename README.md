# 인서비스 정리노트 · 휴대폰용 사이트

신경과 전공의 인서비스 기출 정리 앱을 휴대폰 브라우저에서 여는 개인 공부용 사이트입니다.

- 이 저장소에는 **암호화된 파일(app.bin)만** 있습니다. 내용은 AES-256-GCM으로 암호화되어 있고,
  열쇠는 비밀번호에서 PBKDF2-SHA256(60만 회)으로 만듭니다. 비밀번호 없이는 읽을 수 없습니다.
- index.html이 비밀번호를 받아 브라우저 안에서 풀어 보여 줍니다. 한 번 연 뒤에는 인터넷이 없어도 열립니다.
- 공부 기록(중요표시·메모·형광펜·풀이 기록)은 각 브라우저에만 저장됩니다. 화면 위 📱 버튼으로 백업·불러오기를 할 수 있습니다.
- 사이트 파일은 원본 프로젝트의 `tools/make_site.py`가 만듭니다. 여기서 직접 고치지 마세요.
